# Non-Claims

AutoProof is currently a human-in-the-loop formal proof workspace.

It does not claim:

- autonomous theorem proving,
- proof authority from AI suggestions,
- proof authority from demo mode,
- end-to-end verification of Cathedral Forge,
- formal-to-runtime correspondence,
- immutable provenance from SQLite alone,
- independent human reproduction,
- production authority.

A successful Lean invocation supports only the claim that the submitted formal proposition was accepted by that Lean environment. Higher claims require pinned toolchains, correspondence evidence, Chronicle receipts, replay, and external witness reproduction.
